## Key signatures (normative for all tasks)

```swift
enum Suit: CaseIterable { case spades, hearts, clubs, diamonds }
enum Rank: Int, Comparable { case two=2 ... ace=14, smallJoker=16, bigJoker=17 }
struct Card: Hashable, Identifiable { let rank: Rank; let suit: Suit?; let copy: UInt8 }

enum ComboKind { case single, pair, triple, fullHouse, straight, tube, plate,
                 bomb(size: Int), straightFlush, jokerBomb }
struct Combo { let kind: ComboKind; let cards: [Card]; let rankValue: Int }
// rankValue: trick-relative strength of the shape's anchor rank, with the
// current level rank mapped to 15 (between ace=14 and smallJoker=16).

enum Combo {
  static func detect(_ cards: [Card], level: Rank) -> Combo?       // exact set
  static func allPlayable(from hand: [Card], beating: Combo?, level: Rank) -> [Combo]
}
extension Combo { func beats(_ other: Combo, level: Rank) -> Bool }

enum PlayerAction { case play(Combo), pass }
struct GameEngine {
  private(set) var state: HandState
  mutating func apply(_ a: PlayerAction, by seat: Seat) throws(EngineError)
}
```

Straights/tubes/plates use natural rank order (A may be low: A-2-3-4-5; level
rank counts at its NATURAL position inside sequences, elevated only for
singles/pairs/triples/bombs). Wildcards (heart level cards) substitute any
suit/rank except jokers; detection must try substitutions to find the best combo.
